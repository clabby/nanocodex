# Claude-native tool implementation matrix (2026-09-28)

The Claude backend must **never advertise** `exec_command`, `apply_patch`, `web__run`, `exec`, `wait`, or Responses `tool_search` to Claude. `nanocodex-tools` may supply private host execution primitives behind an explicit Claude adapter and host permission policy; its OpenAI-visible definitions are not the Claude catalog. A tool is only advertised when its implementation, permission boundary and result encoder are available. This inventory tracks the current Claude Code tools reference, not a promise that every item is present in every CLI session/provider/platform.

| Family | Claude Code names | Current status / required implementation |
| --- | --- | --- |
| Files, process, search | `Bash`, `Read`, `Edit`, `Write`, `Glob`, `Grep`, `NotebookEdit`; conditional `PowerShell`, `Monitor`, `LSP` | **Not implemented/advertised.** Build Claude schemas and dedicated handlers for file offsets, exact replacement, notebook cells, search, PTY/background semantics, permissions and path safety. Reuse `nanocodex-tools` host primitives privately where semantics match, not their model contracts. |
| Web | `WebSearch`, `WebFetch` | **Not implemented as Claude Code client tools.** They are not aliases of `web__run`; Claude Code's fetch is prompt-directed, lossy and policy-scoped. Distinct Claude Platform server `web_search_20250305`/`web_fetch_20250910` may be enabled explicitly via `ServerToolDefinition`, executed by Anthropic; synthetic tests cover search results/citations and `pause_turn`, not live search. |
| Extension/discovery | `ToolSearch`, `WaitForMcpServers`, `ListMcpResourcesTool`, `ReadMcpResourceTool`, dynamic MCP names, `Skill` | **Not implemented.** Need neutral MCP catalog, permission filters and Claude deferred tool/reference format. Platform server tool search is distinct. |
| Orchestration | `Agent`, `AskUserQuestion`, `EnterPlanMode`, `ExitPlanMode`, `EnterWorktree`, `ExitWorktree`, `TaskCreate`, `TaskGet`, `TaskList`, `TaskUpdate`, `TaskOutput`, `TaskStop`, `TodoWrite`, `CronCreate`, `CronDelete`, `CronList`, `ScheduleWakeup`, `ListAgents`, `SendMessage`, `Workflow`, `SubagentHandback`, `EndConversation` | **Not implemented.** Map only after common agent lifecycle, durable child authority, user-input handoff and task/scheduler contracts exist. No synthetic local approximation of consequential orchestration. |
| Product/account contingent | `Artifact`, `PushNotification`, `RemoteTrigger`, `ReportFindings`, `SendFeedback`, `SendUserFile`, `ShareOnboardingGuide` | **Not implemented.** Need explicit product capabilities and authorization; CLI availability varies. |
| Claude Platform built-ins | Versioned server search/fetch/code execution/advisor/tool search/MCP; versioned client bash, text editor, computer/browser, memory | Separate from Claude Code names. **Basic server search/fetch request/response support** exists; result variants for search/fetch/tool-search/code-execution are parsed for replay, but most versions/controls and client implementations remain untested/unsupported. |
| User-defined functions | caller-provided Claude `ToolDefinition` | **Implemented** with assistant `tool_use` and single user `tool_result` message, ordered error results; optional parallel execution requires caller to attest independence. No Codex definitions are implicitly loaded. |

Safety design: Claude-visible registry and JSON schemas are independently versioned; translate into a private executor with `(session, turn, tool_use_id)` effect receipts, host approval and filesystem/network boundaries. Do not assume `WorkspaceToolRuntime::exec_command` is sandboxed: its shell accepts absolute workdirs and ignores model-supplied approval flags. Limit result bytes/media and preserve source citations. For side effects, cancellation or unknown outcome must not automatically re-execute the same call. Keep same-tool result blocks together, signed thinking and server result ciphertext unmodified. Native server tools are charged separately; opt-in only. No real subscription token or provider traffic was used in the synthetic tests.
