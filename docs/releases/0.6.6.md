# Nanocodex 0.6.6

Sol now uses GPT-6.1 throughout the CLI, SDKs, managed services, gateways, and native clients. The `sol` alias resolves to `gpt-6.1-sol`, with updated upstream instructions, reasoning defaults, and pricing. Saved sessions retain their original model identity; the retired Sol model ID cannot be continued.

This release also includes the changes merged since v0.6.5.

[Full changelog](https://github.com/gakonst/nanocodex/compare/v0.6.5...v0.6.6)
